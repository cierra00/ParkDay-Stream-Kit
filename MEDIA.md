# Media pack (files not in the repo)

Images, videos and fonts are kept out of the Git repo to keep it small. They ship as one zip whose folders match this repo exactly.

## Get it and install it

1. **Download:** [ParkDay-Stream-Kit-media.zip](https://github.com/cierra00/ParkDay-Stream-Kit/releases/download/media-v1/ParkDay-Stream-Kit-media.zip) (hosted on this repo's Releases page, tag `media-v1`).
   Command line: `curl -L -o ParkDay-Stream-Kit-media.zip https://github.com/cierra00/ParkDay-Stream-Kit/releases/download/media-v1/ParkDay-Stream-Kit-media.zip`
2. Unzip it **into the root of this repo** so the paths line up. PowerShell, from the repo root:
   ```powershell
   Expand-Archive -Path C:\path\to\ParkDay-Stream-Kit-media.zip -DestinationPath . -Force
   ```
   macOS / Linux: `unzip -o ParkDay-Stream-Kit-media.zip -d .`
3. Check: `overlays/low-data-classic.webm` and `overlays/offline-dca-wide.jpg` now exist.
4. Git ignores these files (see `.gitignore`), so they will never be committed by accident.

**Without the pack** everything still works except: the offline / pause screen shows an empty photo window, `lowdata.html` shows nothing, and the lab test bench uses fallback fonts. You can substitute your own photos with the same file names (wide = 3840x2160 or any 16:9, tall = 1080x1920).

Pack built 2026-09-30: 62 files, 7.5 MB zipped.

## Not included, on purpose

| Left out | Why |
|---|---|
| Background music and BRB music | Licensed tracks; get your own |
| Stinger transitions | Third-party asset pack; get your own |
| Starting / countdown / intro scene art, theme song | Channel branding, not part of the planner + overlays kit |
| Test screenshots (`lab/*.png`, `previews/*`, `preview-live/*.png`) | Generated by the tests; re-create them by running the tests |
| Member thank-you lists | Contain viewers' names |
